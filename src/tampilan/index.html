Data produksi s.d. Juli 2026 PRODUKSI: DATA ASLI EFFORT: SIMULASI EX

Data asli. Nama cabang, Kantor Wilayah, kelas cabang, NWP dan profit 2025 dan 2026, target 2026, komposisi channel, serta nama 744 Marketing Officer dan produksi masing-masing, semuanya diambil dari file eReport. Angka di tingkat cabang, Kantor Wilayah, dan nasional sudah dicocokkan dan sama persis dengan file sumbernya.

Masih simulasi. Distribusi harian dan mingguan, semua angka effort dan prospek pada Matrix Distribution, serta nama nasabah dan prospek. Bagian ini disimulasikan karena datanya belum ada, dan akan diganti data sebenarnya setelah integrasi jalan.

Perhatian. File ini memuat angka produksi cabang yang sebenarnya dan nama Marketing Officer dengan angka kinerjanya. Data kinerja perorangan tunduk pada UU Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi. Rahasia internal, tidak untuk diedarkan ke luar perusahaan. Satu entri pada file sumber memuat nama perorangan sebagai nama cabang dan sudah disamarkan menjadi UNIT KHUSUS KANWIL 2, dengan angka yang dipertahankan agar total Kantor Wilayah tetap sesuai.

Catatan periode. File 2025 mencakup dua belas bulan, file 2026 mencakup tujuh bulan. Semua perbandingan tahun memakai rata-rata per bulan supaya setara. Membandingkan totalnya langsung akan memunculkan penurunan semu sekitar 40 persen.

Integrasi ke eReport, Pega ASMPro, Matrix Distribution, dan login tunggal Uniport belum ada. Itu menjadi bagian tim Teknologi Informasi setelah arah ini disetujui.
